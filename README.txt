EVG GLOBAL WEBSITE PACKAGE

This ZIP contains the current EVG Global static website and installable PWA files.

Main website: https://www.evgglobal.ng

Included pages: Home, About, Services, Pricing, Shop, Events, Digital Services, Contact.
PWA files: manifest.webmanifest, service-worker.js, icons/icon-192.png, icons/icon-512.png.

INSTALLATION
- Deploy the contents of this folder to the root of a static hosting project (for example Vercel).
- Keep the folder structure unchanged, especially the icons folder.
- Serve the website over HTTPS for PWA installation and service-worker support.
- Android: open the site in Chrome and choose Install app / Add to Home screen.
- iPhone: open the site in Safari, tap Share, then Add to Home Screen.
